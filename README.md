&#x20;  *# Palakshi Racer*

&#x20;  *A supersonic football game that runs in your browser. One HTML file, works offline.*



&#x20;  *\*\*Play:\*\* https://YOUR-USERNAME.github.io/palakshi-racer/*



&#x20;  *## Controls*

&#x20;  *WASD drive · Shift boost · Space jump · Ctrl slide · C ball cam · Tab scoreboard (its also mobile-friendly)*



&#x20;  *## Build from source*

&#x20;  *cd source*

&#x20;  *npm install*

&#x20;  *npm run build*

&#x20;  *Then copy source/dist/index.html to the repo root as index.html.*
